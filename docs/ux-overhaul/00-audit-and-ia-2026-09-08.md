## 4. Design tokens (from `apps/web/src/theme/terminal-theme.css`)
- **Ink states:** green `--terminal-green:#00ff41` / glow `rgba(0,255,65,.5)`; amber `.terminal-theme--amber` `#ffb000` / `rgba(255,176,0,.5)`; blue `.terminal-theme--blue` `#46a4ff` / `rgba(70,164,255,.5)`. Utilities `.u-amber #ffb000`, `.u-red #ff5a5a`, `.u-idle #8a8f8a`.
- **Glow by distance:** TV `0 0 5px var(--terminal-glow)`; staff `.staff-ui` → `0 0 2px rgba(0,255,65,.3)` (PR #12 ruling).
- **Type:** TV — VT323 + Share Tech Mono, base 24px, h2 32px, h3 28px. Staff — `.staff-ui *{font-family:'JetBrains Mono','Share Tech Mono',monospace}`; headers Share Tech Mono; `.staff-ui button{font-size:20px}`, inputs/selects 19px; caption floor `.u-bump{15px}`. Inline signage previews keep VT323 (`.staff-ui .signage-slot`).
- **Shape:** `.terminal-theme *{border-radius:0!important}`.
- **Tap targets:** ≥44px floor (Scoring desktop-density exception 38px gated `@media(min-width:640px)`); checkboxes 20×20, `accent-color:var(--terminal-green)`.
- **390px gate:** bar/admin phone-first, `md:` adds desktop (reverse of LCARS). Display/host surfaces canvas-first (`DisplayCanvas` 1920×1080 / 1080×1920, `transform:scale()` only).
- **Motion:** `.staffnav-drawer{animation:staffnav-drop 120ms ease-out}`; hover 0.12–0.2s; nothing infinite on display routes.
